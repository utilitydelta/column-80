# Manifesto

Software is design. Code is the design written down. Anything that puts distance between you and your own design is the enemy, no matter how fast it ships.

The industry is selling the opposite. Models that write code you never read. A cloud that keeps a copy of your repo. A subscription you pay every month for the privilege. Slop your coworkers generate and you get to review. None of it makes you a better engineer. It makes you a smaller one.

We build the other thing.

## The model is an averaging machine

An LLM predicts the next token. It emits the statistical average of everything it was trained on. That is imitation, not thought.

- next token prediction is mimicry not reasoning
- it has read everything and understood nothing
- fluency is not intelligence
- there is no mind behind the tokens
- an imitation of understanding is not understanding

So we never let it design. You design. It fills in the average-case body. The compiler catches every place the average is wrong.

## If a model can do it it was not worth doing

Value lives in what the average cannot reach. The moment a model can produce something, its price falls to zero, because everyone else's model produces the same thing.

- what a model can generate converges to zero value
- if the model can write it it was never the hard part
- commodity code earns commodity money which is none
- the work worth doing is the work the model cannot
- do the work that does not converge to zero

This tool exists to delete the typing, not the thinking. The typing was never the valuable part.

## Fuck vibe coding

- if you cannot read it you did not write it
- vibe coding is how juniors stay juniors forever
- the model vibed it and you own the outage
- vibe coders ship the average and sign their name to it
- write code you understand or get out of the way

## Fuck the data harvest

- your code is not their training data
- every prompt to a frontier model is a leak you authorized
- local by default means they get nothing
- when your code leaves the machine it is because you chose it not because we defaulted you into it

## Fuck renting your own craft

- your editor should not have a bill
- stop renting the ability to write code
- it runs on your hardware and charges you nothing
- own your tools do not lease them

## Fuck the dark factory

They promised a factory with the lights off and nobody on the floor. It never worked in steel and it will not work in software. Push the human to the edge and the understanding leaves with them.

- the dark factory was a fantasy in manufacturing and it is a fantasy in code
- push the human to the periphery and quality follows them out the door
- a codebase no human understands is already dead
- automation with no human in the loop is just faster failure
- nobody has shipped a lights-out codebase that worked

## Fuck the slop

- if the model wrote it you review it not me
- stop opening PRs you never read
- slop is what you ship when nobody understands the change
- do not make me review what you could not be bothered to read

## What we build instead

- you design and the model types
- inference runs locally by default
- the compiler is the only reviewer that cannot be gamed
- functions are the unit of generation never the file
- the prompt is a deterministic function of your inputs
- you control everything the model sees
- nothing lands without your accept
- a small model on your box checked by the compiler beats a frontier model in a datacenter guessing

Understand every line you ship. That is the whole product.
